


# 📒 Contact Book Pro

A Python contact management system with CSV storage.

## Features
- ➕ Add contacts
- 👁️ Show all contacts
- 🔍 Search contacts
- ✏️ Update contacts
- 🗑️ Delete contacts
- 💾 Auto save & load from CSV

## How to Run
```bash
python contact_book_pro.py
```

## Technologies Used
- Python
- Pandas
- CSV
